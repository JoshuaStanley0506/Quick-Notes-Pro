# Quick Notes Pro 📝

A lightweight, distraction-free Chrome extension scratchpad built with vanilla JavaScript and Manifest V3. Features live Markdown rendering, interactive task checklists, customizable typography, right-click web clipping, and instant `.md` export.

## Features

- **⚡ Fast Scratchpad:** Auto-saves on every keystroke to `chrome.storage.sync`.
- **👁️ Markdown Preview:** Live rendered view supporting headers, lists, code blocks, blockquotes, and links.
- **✅ Interactive Checklists:** Click `- [ ]` checkboxes in preview mode to toggle task completion state in real time.
- **🎨 Themes & Fonts:** 4 color palettes (Light, Dark, Sepia, Nord) and 5 typography styles (including Roboto, JetBrains Mono, and Merriweather).
- **✂️ Web Clipper:** Highlight any text across the web, right-click, and select "Save to Quick Notes" to append it with the source link.
- **🕒 Quick Log:** Hotkey `Ctrl+Shift+D` (`Cmd+Shift+D`) to insert instant date-time stamps.
- **⬇️ Export:** One-click download as a `.md` Markdown file.
